# 贡献点参考

贡献点写在清单的 `contributes` 对象中。框架级别 1 的贡献点（`inputHandlers`、`tools`、`panels`、`settingsPage`）继续有效；框架级别 2 新增了下列贡献点。除特别说明外，各贡献项都可以通过 `platforms`（`desktop`、`ipad`）限定平台。

## toolPanel：工具面板

在工具栏（桌面版）、玻璃工具面板（iPad 版）中添加一个工具。

| 字段 | 必需 | 说明 |
|---|---|---|
| `id` | 是 | 拓展内唯一，小写字母开头，2–32 个字符 |
| `label` | 是 | 显示名称，字符串或 `{ "zh": "…", "en": "…" }` |
| `tip` | 否 | 说明文字，用作提示与无障碍描述 |
| `icon` | 否 | `"builtin:<名称>"` 使用内置图标，或 `{ "svg": "<path d=\"…\"/>" }`（16×16 线条图，只保留基本图形元素） |
| `order` | 否 | 排列顺序，数值小者在前，默认 100 |
| `action` | 是 | 点按后的动作，见下表 |

| `action.type` | 说明 | 可用范围 |
|---|---|---|
| `page` | 在新标签页中打开拓展页面，需同时提供 `page` | 所有拓展 |
| `panel` | 打开 `panels` 中声明的面板页面，需同时提供 `panel` | 所有拓展 |
| `toolView` | 打开内核中与 `id` 同名的工具视图 | 仅内置拓展 |
| `command` | 运行浏览器命令（`scan:qr`、`snap:solve`） | 仅内置拓展 |

## homepage：主页入口

把本拓展的某个工具同时显示在主页输入框下方。

| 字段 | 必需 | 说明 |
|---|---|---|
| `tool` | 是 | 引用本拓展 `toolPanel` 中的 `id` |
| `order` | 否 | 排列顺序 |

## answerBlocks：回答内容块

处理 AI 回答中带语言标记的代码块（例如 `graph` 块绘制函数图像、`word` 块显示单词卡片）。回答格式规范属于内核；某种内容块由哪个拓展处理由本贡献点决定。处理该语言的拓展被停用时，内容块以普通代码形式显示。

| 字段 | 必需 | 说明 |
|---|---|---|
| `lang` | 是 | 代码块的语言标记 |
| `handler` | 是 | `module.exports.answerBlocks` 中的方法名，参数为 `(payload, ctx)` |
| `timeoutMs` | 否 | 超时时间，默认 120 秒 |

## tools：AI 与任务模式工具

与框架级别 1 相同：`name` 为小写字母、数字与下划线，`parameters` 为 JSON Schema。声明的工具会出现在 AI 对话与任务模式的工具列表中，由 `module.exports.tools` 中的同名方法执行。

## settingsPages：设置页面

| 字段 | 必需 | 说明 |
|---|---|---|
| `id` | 是 | 拓展内唯一 |
| `title` | 是 | 页面标题，字符串或多语言对象 |
| `page` | 是 | 拓展内的 HTML 页面 |

框架级别 1 的 `settingsPage`（单个页面）仍然有效，相当于只有一项的 `settingsPages`。

## importers：文件导入

声明拓展可以导入的文件类型。在桌面版中通过“打开方式”用本浏览器打开匹配的文件时，浏览器调用指定的 `rpc` 方法，参数为 `{ paths: [文件路径…] }`；页面也可通过内核接口 `ext:import` 调用同一导入器。

| 字段 | 必需 | 说明 |
|---|---|---|
| `id` | 是 | 拓展内唯一 |
| `title` | 否 | 文件类型名称 |
| `extensions` | 是 | 小写扩展名（不含点），例如 `["mdx", "mdd"]` |
| `utTypes` | 否 | 对应的统一类型标识符（UTType），供 iPad 版识别文件类型；内置拓展的类型已在应用中声明 |
| `rpc` | 是 | 处理导入的 `rpc` 方法名 |

## urlSchemes：浏览器内部地址（仅内置拓展）

| 字段 | 必需 | 说明 |
|---|---|---|
| `scheme` | 是 | 固定为 `aibrowser` |
| `host` | 是 | 地址中的主机名，例如 `docs` 对应 `aibrowser://docs` |
| `page` | 是 | 打开该地址时显示的页面；同一地址下的其他路径优先匹配拓展内的同名文件 |

## nativeViews：原生视图（仅内置拓展）

| 字段 | 必需 | 说明 |
|---|---|---|
| `id` | 是 | 视图标识 |
| `swift` | 是 | iPad 版中实现该视图的 Swift 类名 |
| `fallback` | 否 | 桌面版及不支持原生视图时使用的网页 |

## inputHandlers 与 panels

与框架级别 1 相同，详见《拓展框架开发指南》第五、六节。
