# Incognito

* New private tab from the four-squares menu (⇧⌘N / Ctrl+Shift+N)
* Separate in-memory session (`aib-incognito`): no shared cookies, history, or passwords
* Dark-purple tab + badge; wiped when the last incognito tab closes
* Agent **SERP search** and **page read** use the private partition so nothing lands in the shared jar
